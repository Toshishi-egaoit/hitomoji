# 日本語IME「ひともじ」

## はじめに

ひともじ、は日本語を主体としたIME（Input Method Environment)である。

このアプリケーションは冨樫雅人氏作成の日本語IME「風」をベースとしつつ、UNICODE対応などの
近代化を図っている。
これによって、風の目指した「文字は自分で選ぶもの」というコンセプトを現代に復活させたいと考えている。

技術的には、風がIMM32ベースの32bitアプリなのに対して、「ひともじ」はTSF（Text Service Framework）
ベースの32bit/64bit両対応アプリとして実装している。

## 動作環境

Windows11での開発、動作確認を行っている。
それより前のWindowsでも動作すると思うが、未確認。

メモリ量やCPU速度などのハードウェア要件は特になし。

## 設定ファイル

基本設定と標準の記号定義はDLLに内蔵されている。
設定を変更しない場合、hitomoji.ini はコメントだけのままでよい。

- hitomoji.ini: ユーザーが変更したい項目だけを記述する。
- hitomoji.sample.ini: 設定項目と推奨値の参照用サンプル。
- hikanji.ini: DLL内蔵の記号定義の一覧。編集しても動作には反映されない。
- my.ini: 独自定義のサンプル。使う場合は hitomoji.ini の @include my.ini を有効にする。

## 注意事項

ひともじは、現在開発途上のIMEである。
現状、ひらがな・かたかな・英字・記号（一部）は入力できる。

また、漢字入力についても可能だが、現状は実用性に欠ける。
独自の先回り置換の記述例は、同梱の my.ini を参照されたい。
